# Signal — Veille personnelle

## Déployer sur Vercel en 4 étapes

### 1. Crée un repo GitHub
- Va sur [github.com/new](https://github.com/new)
- Nom du repo : `signal-info`
- Clique "Create repository"

### 2. Push le code
Ouvre un terminal et tape :
```bash
cd signal-info
git init
git add .
git commit -m "Signal v1"
git branch -M main
git remote add origin https://github.com/TON_USERNAME/signal-info.git
git push -u origin main
```

### 3. Déploie sur Vercel
- Va sur [vercel.com](https://vercel.com) → "Add New Project"
- Connecte ton GitHub → sélectionne `signal-info`
- Framework Preset : **Vite**
- Clique "Deploy"

### 4. C'est en ligne !
Tu obtiens : `signal-info.vercel.app`
